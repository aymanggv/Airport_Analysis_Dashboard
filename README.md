<h2>Airport Analysis Dashboard Explanation</h2>

<h3>Overview:</h3>
<p>This dashboard provides a comprehensive analysis of flight operations, focusing on cancellations and delays across airlines and origins. The visualizations help identify trends, underlying issues, and opportunities for operational improvement in the airline industry.</p>

<hr />

<h3>Key Metrics and Visualizations:</h3>
<ul>
  <li><strong>Total Flights and Cancellations:</strong>
    <ul>
      <li>Total Flights: 7.21M flights analyzed.</li>
      <li>Cancelled Flights: 116.58K flights.</li>
      <li>Diverted Flights: 17.86K flights.</li>
    </ul>
  </li>
  <li><strong>Monthly Trends:</strong>
    <ul>
      <li><strong>Total Flights by Month:</strong> Peaks during summer months (June-August), reflecting increased travel demand.</li>
      <li><strong>Cancelled Flights by Month:</strong> Shows seasonal patterns, helping to prepare for peak cancellation periods.</li>
    </ul>
  </li>
  <li><strong>Cancellation Causes:</strong>
    <ul>
      <li>Weather: 53.17% (61.98K flights).</li>
      <li>Airline/Carrier Issues: 25.29% (29.48K flights).</li>
      <li>National Air System: 21.51% (25.07K flights).</li>
      <li>Security: 0.04% (0.04K flights).</li>
      <li>Insights into leading disruption causes for targeted mitigation strategies.</li>
    </ul>
  </li>
  <li><strong>Analysis by Origin and Airline:</strong>
    <ul>
      <li><strong>Top Origins with Cancellations:</strong>
        <ul>
          <li>Airports like ORD, LGA, and CLT show the highest cancellations.</li>
          <li>HVN and SUN have the highest cancellation percentages relative to their operations.</li>
        </ul>
      </li>
      <li><strong>Airlines with High Cancellations:</strong>
        <ul>
          <li>Airlines such as OH and MQ report elevated cancellation rates, highlighting areas for improvement.</li>
        </ul>
      </li>
    </ul>
  </li>
  <li><strong>Delay Analysis:</strong>
    <ul>
      <li><strong>Average Delays:</strong>
        <ul>
          <li>Arrival Delay: 37.73 minutes.</li>
          <li>Departure Delay: 38.24 minutes.</li>
          <li>Late Aircraft Delay: 49.61 minutes.</li>
        </ul>
      </li>
      <li><strong>Delay Causes:</strong>
        <ul>
          <li>Weather: Average delay of 57.83 minutes.</li>
          <li>Carrier-related: Average delay of 39.74 minutes.</li>
        </ul>
      </li>
      <li><strong>Distance Impact on Delays:</strong> Longer flights exhibit higher average delays.</li>
    </ul>
  </li>
  <li><strong>Geographical Distribution:</strong>
    <ul>
      <li><strong>Cancellation Percentage by Origin:</strong> Map visualizes regions with the highest disruption percentages.</li>
      <li><strong>Cancellations by Airline:</strong> Regional data highlights airline-specific problem areas.</li>
    </ul>
  </li>
  <li><strong>Seasonal Delay Analysis:</strong>
    <ul>
      <li><strong>Arrival and Departure Delays by Month:</strong> Higher delays during summer months align with peak travel periods.</li>
    </ul>
  </li>
</ul>

<hr />

<h3>Purpose:</h3>
<p>This dashboard serves stakeholders like airlines, airport authorities, and policymakers by:</p>
<ul>
  <li>Identifying root causes of cancellations and delays.</li>
  <li>Enabling proactive operational improvements.</li>
  <li>Enhancing customer satisfaction by targeting problem areas.</li>
  <li>Facilitating better airline-airport collaboration.</li>
</ul>

<hr />

<h3>Tools and Techniques Used:</h3>
<ul>
  <li>Data Visualization: Created using Power BI for dynamic and interactive insights.</li>
  <li>Data Cleaning and Aggregation: Ensured data accuracy for impactful analysis.</li>
  <li>Metrics Calculation: Advanced calculations for averages and percentages.</li>
  <li>Geospatial Mapping: Used for visualizing regional trends.</li>
</ul>

<p>This dashboard is a valuable tool for driving data-driven decision-making and improving the reliability of air travel operations.</p>
